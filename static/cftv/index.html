Backup do Banco de Dados SQLite

Gera instantaneamente uma cópia de segurança completa do arquivo monitoring.db contendo todos os gravadores, histórico de incidentes, usuários e logs de auditoria.

Cópia online consistente (sem necessidade de parar o monitoramento).

Instruções para Restauração de Emergência:

Caso precise restaurar este backup em outro computador ou após formatação:

  1. Feche o CFTV Sentinel fechando a janela do servidor.
  2. Renomeie o arquivo de backup baixado para monitoring.db.
  3. Substitua o arquivo dentro da pasta data/monitoring.db do projeto.
  4. Execute o run.bat novamente. Todo o histórico e gravadores serão recuperados!

Bot do Telegram para Alertas em Tempo Real

Receba notificações instantâneas no seu celular, tablet ou computador sempre que um gravador cair, voltar a responder ou reportar problemas de HD. 100% gratuito, sem mensalidades e sem risco de bloqueio.

Dica: Adicione o seu bot ao grupo e use o bot @userinfobot ou @getidsbot para descobrir o Chat ID facilmente.

Como criar seu Bot do Telegram em 1 minuto:
  1. No aplicativo do Telegram, busque pelo contato oficial @BotFather e inicie a conversa.
  2. Envie o comando /newbot, escolha um nome (ex: CFTV Sentinel Bot) e um username que termine em bot.
  3. Copie o Token HTTP API que o BotFather fornecer e cole no campo acima.
  4. Para receber em um Grupo de TI: adicione o seu bot recém-criado no grupo como administrador e informe o Chat ID (começa com -100).
  5. Clique no botão "Disparar Mensagem de Teste" abaixo para validar!
